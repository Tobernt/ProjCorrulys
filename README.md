# ProjCorrulys

Unity C# prototype scripts for player controls, networked characters, inventory persistence and terrain editing.

## Read the code

- `Scripts/AccountData`: character creation, serialization and network synchronization.
- `Scripts/Inventory`: item definitions, inventory data and local persistence.
- `Scripts/Terrain`: graph nodes and mesh processing.
- `Editor`: graph, inventory and terrain editor tools.

The scripts depend on Unity, Mirror networking, ProBuilder and CSG support. This repository contains script assets rather than a complete Unity project; package versions, project settings and scene wiring are not included. It cannot be built or run independently from this checkout.
